3. Dynamic Capacity Allocation and Bid-Price Controls

Source: p. 112–115

In network revenue management, the canonical deterministic linear programming (DLP) approximation provides dual multipliers associated with flight leg capacities. Let \mathcal{J} denote the set of flight itineraries and \mathcal{I} represent physical flight legs. The primal resource allocation problem over finite planning horizon is formulated as:

$$\max \sum_{j \in \mathcal{J}} p_j x_j \quad \text{s.t.} \quad \sum_{j \in \mathcal{J}} A_{ij} x_j \le c_i, \; \forall i \in \mathcal{I}$$
(Equation 3.1 — Canonical DLP Multiplier System)

3.1 Leg-Level Displacement Cost

Let $$\pi_i^*$$ denote the optimal shadow price associated with leg resource constraint $$c_i$$. The dynamic bid-price policy rejects any product request $$j$$ at stage $$t$$ whose fare $$p_j$$ falls below the sum of marginal displacement costs along its constituent legs:

Table 3.1: Optimal Bid Prices across 12-stage Horizon
Leg ID Origin-Dest Capacity Shadow Price $\pi_i$ Status

In non-homogeneous Poisson arrival settings, where $\lambda_t(p) = \alpha e^{-\beta p}$ denotes instantaneous arrival intensity, bid prices serve as deterministic certainty equivalents that approximate the discrete Hamilton-Jacobi-Bellman dynamic programming recursion.
